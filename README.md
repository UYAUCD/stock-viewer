# 株価ビューア 📈

日本株・米国株・指数の現在値と前日比を表示する PWA (iPhone のホーム画面アプリとして利用可能)。

**GitHub Pages 上で動作**し、GitHub Actions が 5 分ごとに Yahoo!ファイナンスからデータを取得してコミットします。自分のサーバーは不要です。

## 使い方 (iPhone)

1. Safari でこのページを開く
2. 共有ボタン → 「ホーム画面に追加」
3. ホーム画面のアイコンからフルスクリーンで起動

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体 (単一ファイル・フレームワーク不要) |
| `symbols.json` | 自動取得する銘柄リスト (追加・編集はここ) |
| `fetch_data.py` | GitHub Actions 用のデータ取得スクリプト |
| `.github/workflows/update.yml` | 5分ごとにデータを取得・コミットするワークフロー |
| `data/quotes.json` | 最新の現在値・前日比 (Actions が自動更新) |
| `data/charts/*.json` | チャート用時系列データ (1分足/5分足/日足) |
| `jpx_names.json` | 日本語社名→銘柄コード辞書 (JPX公式上場銘柄一覧より生成) |

## 銘柄を追加する方法

`[symbols.json](symbols.json)` に1行追加するだけです。数分〜15分以内に Actions が自動でデータを取得します。

```json
{ "symbol": "7203.T", "name": "トヨタ" }
```

- 日本株: `7203.T` (銘柄コード+.T) / 米国株: `AAPL` / 指数: `^N225` / 先物: `NIY=F`

## 注意

- 株価データは Yahoo!ファイナンスのもので、約15分遅延があります
- GitHub Actions のスケジュール実行はキュー状況により数分〜15分程度遅れることがあります
- 投資判断には実際の取引画面をご確認ください
